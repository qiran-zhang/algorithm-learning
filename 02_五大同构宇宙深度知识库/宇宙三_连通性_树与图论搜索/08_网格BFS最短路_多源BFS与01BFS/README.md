## 一、算法由来与痛点（为什么老办法不行）

在棋盘、网格迷宫或无权图中求解“从起点到终点的最少移动步数”时：
1. **DFS 的致命缺陷**：DFS 沿着一条路走到黑，**第一次触碰到终点时的步数极大概率不是最短步数**！若要用 DFS 求最短路，必须搜完整张图的所有路径（组合爆炸，网格稍微大一点立刻超时 TLE）。
2. **多起点痛点**：若有多个起点（如多个火源蔓延、多个感染源），若对每个起点单独跑一次最短路，复杂度将翻 $K$ 倍。
3. **边权非1的局限**：普通 BFS 只能处理边权全为 1 的场景，如果移动有的是“免费传送”（边权为 0），有的是“走一步”（边权为 1），普通队列会破坏层级单调性。

**BFS（Breadth-First Search，广度优先搜索）** 应运而生：利用先进先出（FIFO）队列，像水波纹荡漾一样按层向外扩展。**在边权均等的图中，任何节点被队列第一次弹出的瞬间，记录的距离必然是最短距离！**

## 二、算法原理与灵感突破（怎么想到的与底层机制）

### 1. 核心灵感：水波扩散与层序遍历
把起点看作一滴水落入湖面，第 0 秒波纹在起点，第 1 秒扩散到所有距离为 1 的相邻格子，第 $k$ 秒扩散到所有距离为 $k$ 的格子：
```text
   Level 2:   .  . (2) .  .
   Level 1:   . (2)(1)(2) .
   Level 0:  (2)(1)[S](1)(2)   <- 水波纹按步数严格单调递增展开
   Level 1:   . (2)(1)(2) .
   Level 2:   .  . (2) .  .
```

### 2. 三大核心变式
1. **标准单源 BFS**：
   - 维护 `dist[r][c]` 矩阵，初始化为 $\infty$。
   - 起点 `(sr, sc)` 入队，`dist[sr][sc] = 0`。
   - 每次出队 `(r, c)`，遍历上下左右 4 个方向向量 `[(-1,0), (1,0), (0,-1), (0,1)]`，若未访问且非障碍物，更新 `dist` 并入队。
2. **多源 BFS（超级源点法）**：
   - 典型题目：`LeetCode 994 腐烂的橘子`、`LeetCode 542 01矩阵`。
   - **破局妙招**：无需虚拟超级源点，直接在第 0 步将所有初始起点**一次性全部推入队列**，随后正常运行标准 BFS 即可！
3. **0-1 BFS（双端队列 deque）**：
   - 遇到边权为 0（如滑冰顺风、传送阵）：`queue.appendleft(next_node)`，依然在当前层处理；
   - 遇到边权为 1（正常走步）：`queue.append(next_node)`，留到下一层处理。
   - 时间复杂度严格 $O(V + E)$，比堆优化 Dijkstra 节省一个 $\log$ 常数！

## 三、适用范围与题眼特征

### 题眼关键词识别
- **“网格迷宫”、“最少步数”、“最短跳跃次数”、“最少转换时间”**。
- **“所有陆地距离最近海洋的最大距离”、“多个病毒同时扩散”** $\to$ 多源 BFS。
- **数据范围**：网格大小 $N, M \le 1000$，总格子数 $10^6$，必须在 $O(N \times M)$ 内求解。

### 竞赛避坑防线
- **Python 千万别用 `list.pop(0)`**！它的时间复杂度是 $O(N)$，会让 BFS 整体退化为 $O(N^2)$ 惨遭 TLE。**必须使用 `collections.deque.popleft()`（严格 $O(1)$）**！
- **入队即标记 `visited`**：很多同学在出队时才标记访问，这会导致同一个格子被相邻多个点重复推入队列多次，造成内存溢出与死循环。

## 四、算法特点与时空复杂度

| 维度 | 特点 |
| :--- | :--- |
| **时间复杂度** | 网格图为 $O(R \times C)$，通用图为 $O(V + E)$。每个状态恰好入队、出队一次。 |
| **空间复杂度** | $O(R \times C)$，最坏情况下队列长度为对角线或网格边界节点数。 |
| **算法性质** | 边权非负且全等时，天然保证最短路性质。 |

```cpp
#include <vector>
#include <queue>
using namespace std;

// 408 考点：基于队列的图广度优先遍历与无权图单源最短路径
int bfs_grid(const vector<vector<int>>& grid, pair<int,int> start, pair<int,int> target) {
    int R = grid.size(), C = grid[0].size();
    vector<vector<int>> dist(R, vector<int>(C, -1));
    queue<pair<int, int>> q;
    
    q.push(start);
    dist[start.first][start.second] = 0;
    int dx[] = {-1, 1, 0, 0};
    int dy[] = {0, 0, -1, 1};
    
    while (!q.empty()) {
        auto [r, c] = q.front();
        q.pop();
        if (r == target.first && c == target.second) return dist[r][c];
        
        for (int i = 0; i < 4; ++i) {
            int nr = r + dx[i], nc = c + dy[i];
            if (nr >= 0 && nr < R && nc >= 0 && nc < C && grid[nr][nc] == 0 && dist[nr][nc] == -1) {
                dist[nr][nc] = dist[r][c] + 1;
                q.push({nr, nc}); // 入队即记录距离并标记
            }
        }
    }
    return -1;
}
```
