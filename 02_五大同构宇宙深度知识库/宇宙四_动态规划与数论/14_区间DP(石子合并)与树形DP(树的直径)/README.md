# 14_区间DP(石子合并)与树形DP(树的直径)：结构化状态转移的高阶形态

> **适用竞赛**：蓝桥杯（B组/A组大题必考）、力扣进阶 Hard 题、大厂机试架构级动态规划、408 树结构遍历高级应用

---

## 一、算法由来与痛点（为什么老办法不行）

1. **贪心策略在相邻合并中的惨败**：在“相邻石子合并”问题中，若每次贪心挑选最小的两堆合并，局部最优会导致后续无法与更优的大堆衔接，惨遭错误解答（贪心只适用于 Huffman 树那种任意挑选的场景，不适用于相邻约束）。
2. **线性 DP 无法刻画区间包容性**：普通 $dp[i]$ 只能表示前 $i$ 个元素的状态，无法表达“由两个小区间 $[i, k]$ 与 $[k+1, j]$ 融合诞生大区间 $[i, j]$”的拓扑层级。
3. **树形结构的递归状态爆炸**：在一棵多叉树上求“不相邻节点的最大权值和”（如没有上司的舞会），若用暴力枚举子集，复杂度为 $O(2^N)$。

**区间 DP** 与 **树形 DP** 提供了结构化分解的终极范式：
- **区间 DP**：按**区间长度从小到大**为阶段，大区间的解严格建立在已解决的小区间之上。
- **树形 DP**：以**树的后序遍历（DFS 回溯）** 为执行序，父节点的状态由其所有子树状态汇聚而成，时间严格为 $O(N)$！

---

## 二、算法原理与灵感突破（怎么想到的与底层机制）

### 1. 区间 DP 核心机制：按长度递增填表
- **状态定义**：$dp[i][j]$ 表示将闭区间 $[i, j]$ 彻底合并成一堆的最小代价。
- **状态转移**：枚举中间分界点 $k$（$i \le k < j$）：
  $$dp[i][j] = \min_{k=i}^{j-1} \big( dp[i][k] + dp[k+1][j] \big) + \sum_{x=i}^j nums[x]$$
  其中区间和 $\sum_{x=i}^j nums[x]$ 利用**前缀和**在 $O(1)$ 内取出。
- **三重循环铁律**：
  1. 最外层：枚举区间长度 $len = 2 \to n$
  2. 第二层：枚举左端点 $i = 0 \to n - len$
  3. 最内层：枚举分割点 $k = i \to j - 1$

### 2. 树形 DP：自底向上的树上汇总
- **树的直径问题（LeetCode 543 / 树的几何中心）**：
  - 穿过节点 $u$ 的最长简单路径长度 = $u$ 向左子树延伸的最大深度 + $u$ 向右子树延伸的最大深度。
  - 在 DFS 后序遍历时，子节点向父节点返回“以当前节点为起点的最大单向深度”，同时在节点内部更新全局最大直径！

## 三、适用范围与题眼特征

### 题眼关键词识别
- **“只能合并相邻两堆”、“最优加括号”、“戳气球（Burst Balloons）”、“多边形三角剖分”** $\to$ 区间 DP。
- **“树上选点不能相邻”、“求树中任意两节点间的最远距离（树的直径）”、“树的重心”** $\to$ 树形 DP。
- **数据范围特征**：
  - 区间 DP：$N \le 300 \sim 500$（$O(N^3)$ 运算量在 $10^7$ 内）。
  - 树形 DP：$N \le 10^5$（树边数仅 $N-1$，线性 $O(N)$ 遍历）。

---

## 四、算法特点与时空复杂度

| 算法 | 时间复杂度 | 空间复杂度 | 核心要害 |
| :--- | :--- | :--- | :--- |
| **区间 DP** | $O(N^3)$ | $O(N^2)$ | 阶段必须是区间长度，结合前缀和常数优化 |
| **树形 DP** | $O(N)$ | $O(N)$ | 后序遍历回溯时自底向上状态转移 |

```cpp
#include <vector>
#include <algorithm>
using namespace std;

// 408 考点：二叉树深度与树的直径递归求解
class Solution {
    int max_diameter = 0;
public:
    int dfs(TreeNode* root) {
        if (!root) return 0;
        int left_depth = dfs(root->left);
        int right_depth = dfs(root->right);
        
        // 后序遍历阶段更新全局最长路径
        max_diameter = max(max_diameter, left_depth + right_depth);
        return 1 + max(left_depth, right_depth); // 返回给父节点的最大单链高度
    }
    int diameterOfBinaryTree(TreeNode* root) {
        dfs(root);
        return max_diameter;
    }
};
```
