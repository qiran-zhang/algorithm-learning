# 13_数论三剑客_切片筛_GCD_快速幂逆元：从暴力试除到代数飞跃

> **适用竞赛**：蓝桥杯（数学题、大数取模、组合计数几乎必出大题）、力扣数学专题、ACM/ICPC 初等数论基石

---

## 一、算法由来与痛点（为什么老办法不行）

1. **区间素数统计的算力黑洞**：单个数判素数可用 $O(\sqrt{n})$ 试除，但在求 $1 \sim 10^7$ 范围内所有素数时，试除法累计计算量为 $\sum \sqrt{i} \approx O(n \sqrt{n}) \approx 3 \times 10^{10}$，直接超时几十倍。
2. **大数幂乘的溢出与超时**：计算 $a^b \pmod{10^9+7}$（其中 $b = 10^{18}$），若循环相乘 $b$ 次，复杂度为 $O(b)$ 绝不可行；若直接算 $a^b$，数字长度达上亿位，内存瞬间撑爆。
3. **模运算下除法的失效痛点**：加减乘皆可自由取模，唯独**除法不能直接取模**：
   $$(A / B) \bmod M \ne ((A \bmod M) / (B \bmod M)) \bmod M$$
   计算组合数 $C_n^k = \frac{n!}{k!(n-k)!} \pmod M$ 时，若直接除，取模后的整数无法整除！必须通过**乘法逆元**将除法转化为乘法：$(A / B) \equiv A \times B^{-1} \pmod M$。

## 二、算法原理与灵感突破（怎么想到的与底层机制）

### 1. 埃氏筛与 Python 独门切片优化
- **核心灵感**：一个素数的倍数必然是合数。发现素数 $p$ 后，无需重复判断，直接把 $2p, 3p, 4p, \dots$ 全体批量划掉。从 $p^2$ 开始划即可（更小的倍数早被前面的素因子划过了）。
- **Python 独创黑科技**：传统两重循环慢在 Python 解释器开销，但利用 Python 列表切片步长赋值 `is_prime[p*p::p] = [False] * len(...)`，由 C 底层连续内存写入，**0.2 秒内即可筛出 $10^7$ 级别全部质数**！

### 2. 快速幂（Binary Exponentiation）
- **核心灵感**：二进制倍增拆分指数。
  例如求 $3^{13}$，因为 $13 = (1101)_2 = 8 + 4 + 1$：
  $$3^{13} = 3^8 \times 3^4 \times 3^1$$
  通过不断自乘平方（$3 \to 3^2 \to 3^4 \to 3^8$），仅需 4 次自乘即可得到结果，复杂度从 $O(b)$ 骤降至 $O(\log b)$！

### 3. 费马小定理与乘法逆元
- **费马小定理**：若 $M$ 为质数，且 $\gcd(a, M) = 1$，则：
  $$a^{M-1} \equiv 1 \pmod M \implies a \times a^{M-2} \equiv 1 \pmod M$$
- **结论**：$a^{M-2} \pmod M$ 就是 $a$ 在模 $M$ 下的乘法逆元 $a^{-1}$！
- 求解方法：直接调用快速幂计算 $\text{pow}(a, M-2, M)$！

## 三、适用范围与题眼特征

### 题眼关键词识别
- **“求 $1 \sim N$ 中的素数个数 / 寻找最大质因子”** $\to$ 素数筛。
- **“结果对 $10^9+7$ 或 $998244353$ 取模”** $\to$ 模运算、快速幂。
- **“求组合数 $C(N, K) \bmod (10^9+7)$，且 $N \le 10^5$”** $\to$ 预处理阶乘逆元表。

### 竞赛避坑防线
- **逆元适用前提**：费马小定理要求模数 $M$ **必须是质数**，且 $a$ 不是 $M$ 的倍数。若模数不是质数，必须使用拓展欧几里得算法（`exgcd`）求逆元。

## 五、快捷库/一行流与 C++ 408 对照

### Python 标准库神级一行流
```python
import math

# 1. 欧几里得 GCD 最大公约数
g = math.gcd(a, b)

# 2. Python 内置三参数快速幂（C 底层超高速实现，远快于手写循环）
ans = pow(base, exp, mod)  # 严格执行 (base^exp) % mod

# 3. 费马小定理求逆元（Python 3.8+ 支持负指数逆元！）
inv = pow(a, -1, mod)      # 一行搞定逆元！
# 兼容旧版本：pow(a, mod - 2, mod)
```

#include <numeric>
#include <iostream>
using namespace std;

// 408 / 竞赛考点：快速幂与最大公约数
long long qpow(long long a, long long b, long long m) {
    long long res = 1;
    a %= m;
    while (b > 0) {
        if (b & 1) res = (res * a) % m;
        a = (a * a) % m;
        b >>= 1;
    }
    return res;
}

// 费马逆元
long long mod_inverse(long long a, long long p) {
    return qpow(a, p - 2, p);
}
