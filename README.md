## 🚀 极速开箱启动指南

### 方式一：可视化交互工作台（推荐，零配置）
在 Windows 资源管理器中，**直接鼠标双击根目录下的 `index.html`**，即可瞬间启动：
- **可视化实验室**：覆盖 35 种核心算法（十大排序、二分、双指针、KMP、Manacher、单调栈/队列、堆、并查集、字典树、树状数组、线段树、网格 BFS/DFS、Dijkstra、拓扑排序、Kruskal、欧拉回路、背包 DP、区间 DP、LIS、素数筛、辗转相除法、位运算、博弈论等），支持单步调试、双向时光倒流进度条、变量与代码同步高亮。
- **88阶梯任务看板**：全序排列的 22 大考点，每个考点标配 4 级分任务（算法理解打卡、简单母题、中等突破、困难综合题），点击题目直接跳转至力扣/洛谷在线网页答题，打卡状态自动保存在浏览器本地（`localStorage`）。
- **五维深度知识库**：一键切换沉浸式卡片阅览，系统化夯实算法底层逻辑。
- **⚡ N秒推候选算法计算器**：点击右上角闪电按钮，输入考场题目给定的数据规模 $N$，系统瞬间计算允许的最大操作量并精确推荐候选算法模型！

### 方式二：本地 Python 源码与脚手架验证（进阶）
若你想在本地查看源码或进行挖空练习：
```bash
# 运行全项目统一自动化测试驱动器（34 模块自动化验证）
```

## 🏆 88阶梯任务打卡体系说明

每一个考点均严格标配 **4 级阶梯任务（Sub-Tasks）**：
1. **`[算法内功打卡]`**：掌握「由来痛点、原理灵感、适用范围、算法特点、快捷库」五维模型。
2. **`[简单母题]`**：核心基础母题，点击卡片中的题目名称即可直接前往力扣/洛谷/蓝桥在线页面刷题。
3. **`[中等突破]`**：进阶变式真题，强化举一反三能力。
4. **`[困难综合]`**：高阶综合题，附带“跨知识点前置依赖提示”（例如：若该题综合了线段树与动态规划，卡片会明确标注“建议先学完XX算法后再来攻克”）。

打卡勾选状态将即时持久化到浏览器中，页面顶部与看板头部会实时显示你的总体打卡进度（例如：`35 / 88 (39.8%)`）与各个组别（C组、B组、A组、408）的达标百分比！
