# 看数据范围 N 秒推算法与 OI 赛制四阶骗分法则

> **考场核心公理**：现代竞技评测机 1.0 秒内所能允许的最大基本计算次数约为：
> - **C/C++ 语言**：$10^8$ 次运算（一亿次）
> - **Python 3 语言**：约 $1.5 \times 10^7 \sim 2.0 \times 10^7$ 次运算（一千五百万到两千万次）

只要审题看清题目给出的输入数据规模 $N$，就能在 3 秒内精确反推出命题人期望你使用的算法！

---

## 一、输入规模 $N$ 与目标算法秒推对照表

| 输入规模 $N$ | 允许最大时间复杂度 | 唯一/推荐目标算法体系 | 典型考查题型 |
|---|---|---|---|
| $N \le 10$ | $O(N!) \sim O(N^2 \cdot 2^N)$ | 全排列递归枚举、DFS 深度遍历、旅行商问题状压 | 旅行商 TSP、N 皇后、全排列匹配 |
| $N \le 20$ | $O(2^N) \sim O(N \cdot 2^N)$ | 状态压缩动态规划 (Bitmask DP)、折半枚举 (Meet-in-the-middle) | 背包子集和、蒙德里安的梦想、状压连通 |
| $N \le 100$ | $O(N^4) \sim O(N^3)$ | Floyd-Warshall 全源最短路、区间 DP（如石子合并）、高斯消元 | 多源最短路、多边形剖分、线性方程组求解 |
| $N \le 500$ | $O(N^3)$ | 矩阵乘法、Floyd 算法、三维动态规划 | 稠密图最短路、复杂多维背包 |
| $N \le 2000 \sim 5000$ | $O(N^2)$ | 基础冒泡/插入/选择排序、二维动态规划 (LCS/LIS)、两重循环双指针 | 字符串编辑距离、二维方格走路 DP |
| **$N \le 10^5 \sim 2 \times 10^5$** | **$O(N \log N)$** | **快速排序、归并排序、堆排序、二分查找/二分答案、线段树、树状数组、Dijkstra 堆优化、并查集** | **蓝桥杯与力扣 70% 大题的主战场！** |
| **$N \le 10^6$** | **$O(N)$** | **相向双指针、滑动窗口、单调栈、单调队列、前缀和与差分、KMP、线性筛、拓扑排序** | **双指针滑窗极值、快速读入线性扫描** |
| $N \le 10^9 \sim 10^{18}$ | $O(\log N) \sim O(1)$ | 二分快速幂、欧几里得辗转相除法 (GCD)、数论公式推导、矩阵快速幂 | 大数幂模、斐波那契第 $10^{18}$ 项 |

## 二、OI 赛制“四阶骗分”黄金法则

蓝桥杯采用的是标准的 **OI 赛制（按通过测试点比例给分）**。这意味着即使你写不出能通过 $100\%$ 大数据的满分正解，只要能通过部分测试点（例如 $30\% \sim 60\%$），依然能拿到宝贵的赋分！在省赛中，往往多骗 20 分就是**省二到省一**的决定性差距！

### 阶梯一：特判骗分（保底 10% 分数）
- **适用场景**：题目包含极端特殊值边界，或者有特定的边界条件说明（如 $K = 0$、$N = 1$、全部元素相等、树退化为一条单向链表）。
- **打法**：在代码最前面加 `if` 判断：
  ```python
  if n == 1:
      print(0)
      sys.exit(0)
  if k == 0:
      print(sum(nums))
      sys.exit(0)
  ```

### 阶梯二：暴力全排列与暴力递归（稳吃 30% 分数）
- **适用场景**：题目要求在 $N \le 10^5$ 上求最优解，正解需要高级线段树或复杂 DP，而你考场上想不出来。但题目说明了“前 30% 数据 $N \le 10$”。
- **打法**：果断写最简单的 DFS 暴力爆搜或三重 `for` 循环暴力遍历，只针对小数据范围求值，千万不要交白卷！

### 阶梯三：打表找规律（吃满 40% - 60% 分数）
- **适用场景**：数学题、博弈论题、递推计数题、找某些特殊序列的第 $N$ 项。
- **打法**：
  1. 先写一个极其简短的暴力爆搜程序，在本地离线运行出前 20 项的结果；
  2. 观察输出的数列：是否是等差、等比、斐波那契变式、差分序列或存在周期循环节？
  3. 发现规律后直接在正式提交代码中写一个纯递推公式或直接把结果做成固定数组查表输出！

### 阶梯四：贪心近似与随机化退火（博取 50% - 80% 奇迹分）
- **适用场景**：NP 完全问题或复杂图论/背包题，状态过多无法精确求解。
- **打法**：
  1. 先按照直觉写一个贪心排序或局部最优选取策略；
  2. 跑多次带微小扰动的随机贪心，取多次试验中的最优解输出；
  3. 在评测机时间超时（接近 0.9 秒）前强制停止并输出当前找到的历史最优解！
